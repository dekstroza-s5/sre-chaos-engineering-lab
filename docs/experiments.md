# Experiment process

For each scenario record:

1. hypothesis;
2. steady-state metrics;
3. blast radius;
4. abort conditions;
5. injection command and UTC time;
6. observed metrics, alerts and logs;
7. mitigation and recovery time;
8. conclusion and follow-up work.

Abort when the experiment leaves the dedicated namespace, control-plane health changes, recovery exceeds the agreed window or observability is unavailable.
